# Taylor Series
A simple code to visualize the curve fitting of the Taylor Series on the function sin(x)

## Requirements:-
- [Python](python.org)
- [Numpy](numpy.org)
- [Matplotlib](matplotlib.org)

## Usage:-
- Use [main.py](main.py)
- It will generate the desired number of images in the [Temporary Image](/temp_img) folder.
- Any other software (like [Blender](blender.org)) could be used to convert the image sequence to the desired output.

## Current Limitation:-
- Only generates the raw image sequence
- Requires the use of other software to create a video file.
